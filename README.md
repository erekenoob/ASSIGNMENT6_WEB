## Description
This project demonstrates the fundamentals of jQuery:
- **Part 1 (`index.html`):** Setup via CDN, `$(document).ready()`, selecting by ID, class, tag, and modifying content/styles with `.text()`, `.html()`, and `.css()`.
- **Part 2 (`effects.html`):** Visibility methods (`.hide()`, `.show()`, `.toggle()`), Fade effects (`.fadeIn()`, `.fadeOut()`, `.fadeToggle()`), and Slide effects (`.slideUp()`, `.slideDown()`, `.slideToggle()`).
- **Part 3 (`dom.html`):** Adding/removing list items (`.append()`, `.prepend()`, `.remove()`), changing attributes (`.attr()`), and live form preview (`.val()`).
- **Part 4 (`animations.html`):** Basic, sequential, and combined animations using `.animate()`.
- **Part 5 (`gallery.html`):** Interactive Image Gallery with fade transitions and `.animate()` image enlargement.
